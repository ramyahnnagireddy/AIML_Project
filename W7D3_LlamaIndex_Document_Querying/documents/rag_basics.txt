Retrieval-Augmented Generation (RAG) combines document retrieval with language generation. A typical RAG system splits documents into chunks, converts chunks into embeddings, and stores the vectors in a vector database. When a user asks a question, the system retrieves relevant chunks and provides them as context to a language model. ChromaDB is a vector database that can store embeddings and associated document metadata. LlamaIndex provides tools for connecting data sources, creating indexes, and querying retrieved information. RAG can improve grounding in supplied documents, but retrieved content and generated answers still require evaluation.

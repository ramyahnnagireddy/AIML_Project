\# W2D3 - Handling Imbalanced Data with SMOTE



\## Objective



Demonstrate how to handle an imbalanced binary classification dataset using

SMOTE (Synthetic Minority Over-sampling Technique).



\## Workflow



1\. Create an imbalanced classification dataset.

2\. Split the dataset using stratification.

3\. Apply SMOTE only to the training data.

4\. Verify that the minority class is balanced.

5\. Train a Logistic Regression model.

6\. Evaluate the model on the untouched test data.
